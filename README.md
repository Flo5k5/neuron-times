# The Neuron Times

Daily AI watch newspaper. Broadsheet old-school visual style with 4 themes commutables.

**Live :** [https://neuron-times.com](https://neuron-times.com)
**Mirror redirect :** `the-ai-loop.com` → `neuron-times.com` (301)

## What is this

A daily-generated, static HTML report aggregating the most significant signals from the AI ecosystem — frontier models, coding agents, infrastructure, research papers, community signals. Inspired by traditional broadsheet newspapers (NYT, Le Monde, Guardian) with modern interactive enhancements (theme switcher, multi-page navigation, 3D page transitions).

The motto says it all : **« All the AI that's fit to print »**.

## Repo structure

```
neuron-times/
├── reports/                    Daily reports (YYYY-MM-DD.html + .json)
├── latest.html                 Mirror of the most recent report (stable URL)
├── index.html                  Archive index, auto-regenerated by GitHub Actions
├── CNAME                       Custom domain config for GitHub Pages
├── build_index.py              Python script that regenerates index.html from reports/*.json
├── .github/workflows/
│   └── regenerate-index.yml    GitHub Actions workflow (rebuild index on push reports/)
└── README.md
```

## How a report gets published

1. Each morning around 7am CET, a automated daily pipeline :
   - fetches AI sources (~116 RSS feeds, blogs, GitHub releases)
   - synthesizes via Claude (Opus 4.7 / Sonnet 4.6, via Claude)
   - renders the report in 3 formats (markdown source-of-truth, JSON data, HTML themed presentation)
   - pushes `reports/YYYY-MM-DD.html` + `reports/YYYY-MM-DD.json` + updated `latest.html` to this repo
2. The push triggers `.github/workflows/regenerate-index.yml` which :
   - reads all `reports/*.json`
   - regenerates `index.html` with a chronological archive
   - commits with `[skip ci]` to avoid loops
3. GitHub Pages serves the site at `https://neuron-times.com`

The generator runs automatically every morning.

## Themes available in each report

Each report HTML embeds 4 commutable themes (top-bar switcher, persisted via localStorage) :

- **Times Victorien** — Bodoni Moda, monochrome strict ivoire (1850-1900 Times of London style)
- **Le Monde Classique** — EB Garamond + bleu de Prusse (1960-1980 broadsheet français)
- **Almanach Sépia** — IM Fell English + Pinyon Script + ornements floraux (1900-1920 journal rural)
- **Gazette du Soir** — Abril Fatface + bandeau rouge sang (1930-1960 tabloïd dramatique)

## Self-contained

Each HTML report is fully self-contained : CSS inline, Google Fonts via CDN, JS minimal (theme switcher + page navigation). Works offline once loaded, portable, archivable.
