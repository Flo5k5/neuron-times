Google I/O 2026 dévoile Gemini Omni et Antigravity 2.0, OpenAI réplique avec une percée mathématique

Mountain View annonce une centaine de nouveautés autour de son écosystème Gemini ; à San Francisco, un modèle d'OpenAI réfute une conjecture vieille de quatre-vingts ans en géométrie discrète.

De la rédaction — 21 mai 2026

La conférence annuelle Google I/O, refermée cette semaine, a vu DeepMind et Google placer leur ligne Gemini au centre du dispositif. Parmi la centaine d'annonces recensées par le blog officiel, deux pièces maîtresses émergent : Gemini Omni, présenté comme le successeur multimodal de la famille, et Google Antigravity 2.0, nouvelle itération de la plateforme d'agents de développement. Le résumé exhaustif est publié sur le blog Google.

Le même jour, OpenAI a annoncé qu'un de ses modèles a réfuté une conjecture centrale en géométrie discrète, en résolvant le problème dit des distances unités, ouvert depuis quatre-vingts ans. L'entreprise présente le résultat comme un jalon dans l'usage de modèles de raisonnement pour la recherche mathématique fondamentale, après une série d'expériences déjà documentées dans la communauté.

En coulisses, l'API d'OpenAI poursuit son nettoyage : depuis le 12 mai, les snapshots dall-e-2, dall-e-3 et la Realtime API Beta ont été retirés au profit de gpt-image-2 et de la Realtime API en disponibilité générale, indique le changelog officiel. Une journée riche, qui confirme la bascule du secteur vers une compétition à deux étages : produits grand public d'un côté, capacités scientifiques de l'autre.

II. Harnais & agents de code

Claude Code passe en 2.1.145

La version 2.1.145 introduit claude agents --json pour piloter les sessions depuis tmux ou des status bars, ajoute agent_id/parent_agent_id aux spans OTEL claude_code.tool, et corrige un contournement de prompt de permission via assignations de variables Bash. La précédente 2.1.144 avait étendu /resume aux sessions --bg.

Codex CLI publie une 0.132.0 plus structurée

OpenAI a livré Codex 0.132.0 avec une authentification de première classe pour le SDK Python (clé API, flux ChatGPT et device code), des TurnResult enrichis, et un codex exec resume --output-schema qui préserve le contexte de session tout en imposant une sortie JSON. Trois pre-releases 0.133.0-alpha ont suivi dès le lendemain.

Gemini CLI : un preview 0.43 pour rentrer dans le rang

Le robot de release de Google a poussé v0.43.0-preview.1, une cherry-pick de stabilisation, tandis que les nightlies de la branche 0.44 introduisent un flag adk.agentSessionSubagentEnabled pour les sous-agents.

III. Moteurs & inférence

OpenAI API : retraits et nouveaux modèles d'images

Le changelog OpenAI entérine la déprécation au 12 mai de dall-e-2, dall-e-3 et de la Realtime API Beta. La Responses API gagne un return_token_budget pour des recherches web GPT-5 plus longues, tandis que gpt-image-2 devient le modèle d'image recommandé.

Codex Plugin : OpenAI s'invite dans son propre IDE

OpenAI a publié un plugin Developers pour Codex, censé guider la configuration des API et l'accès à la plateforme depuis l'environnement Codex, en miroir des plugins concurrents pour Claude Code et Gemini CLI.
